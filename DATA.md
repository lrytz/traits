# Where the data comes from

What earns an entry, and the shape of an entry, are in [`PLAN.md`](PLAN.md).
This is the source list for curating them.

## Scope

Changes since Scala 3.0.0. Features that shipped *in* 3.0.0 are out of scope,
at least for now.

## Sources

**Releases and announcements**

* Scala blog — https://www.scala-lang.org/blog/ (paginated: `/blog/2/`, …),
  e.g. https://www.scala-lang.org/news/3.8/
* GitHub release notes for every `3.x.0` —
  e.g. https://github.com/scala/scala3/releases/tag/3.8.0
* Milestones, for what is planned and when —
  https://github.com/scala/scala3/milestones

**SIPs**

* The SIP list — https://docs.scala-lang.org/sips/all.html
* SIP repository, open and closed PRs — usually linking the forum thread —
  https://github.com/scala/improvement-proposals/pulls
* Meeting results and notes (not fully up to date) —
  https://docs.scala-lang.org/sips/meeting-results.html

**Reference**

* Scala 3 language reference — https://docs.scala-lang.org/scala3/reference/
* What "preview" means, versus experimental —
  https://docs.scala-lang.org/scala3/reference/preview/index.html and
  https://github.com/scala/scala3/issues/22044
* The standard library change process (SLC) —
  https://github.com/scala/scala3/blob/main/docs/_docs/contributing/procedures/contributing-to-stdlib.md

**To migrate in**
